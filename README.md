# church-web

**Path:** `church-web/` in the GLA monorepo.

Vite + React app for God-Life Assembly (marketing site). Deployed with Cloudflare Pages; see `wrangler.toml` in this folder.

From this directory:

```bash
npm install
npm run dev
npm run build
```

Git mirror: [github.com/glaj-tech/church-web](https://github.com/glaj-tech/church-web) (subtree push from monorepo root — see `../docs/git-workflow.md`).
